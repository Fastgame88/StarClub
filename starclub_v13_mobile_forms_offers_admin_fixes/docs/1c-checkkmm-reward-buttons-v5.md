# Star Club v5 — кнопки в ЧекККМ

## Ідея
Кнопки для товарів за зірки треба ставити не у форму вибору дисконтної картки, а прямо в документ `ЧекККМ → ФормаДокумента`.

У формі вибору картки залишайте тільки:
- Оновити список
- Пошук Star Club
- Баланс

У `ЧекККМ` додайте кнопки:
- Код Star Club — перевірити
- Код Star Club — списати
- Код Star Club — скасувати

## Код модуля форми ЧекККМ

```1c
Процедура ПеревіритиКодStarClubНажатие(Элемент)

	StarClubИнтеграция.ЗапитатиТаПеревіритиКодТовараЗаЗірки();

КонецПроцедуры


Процедура СписатиКодStarClubНажатие(Элемент)

	НомерЧека = "";
	Попытка
		НомерЧека = Строка(Номер);
	Исключение
		НомерЧека = "";
	КонецПопытки;

	StarClubИнтеграция.ЗапитатиТаПідтвердитиКодТовараЗаЗірки(НомерЧека);

КонецПроцедуры


Процедура СкасуватиКодStarClubНажатие(Элемент)

	StarClubИнтеграция.ЗапитатиТаСкасуватиКодТовараЗаЗірки();

КонецПроцедуры
```

## Як працює
1. Клієнт у Star Club створює QR/ручний код на товар.
2. Касир у ЧекККМ натискає `Код Star Club — перевірити`.
3. Вводить код з додатку.
4. 1С показує товар, кількість, ціну в грн, ціну в зірках і статус.
5. Касир додає товар у чек звичайним способом.
6. Після проведення/пробиття натискає `Код Star Club — списати`.
7. Star Club списує зірки, код стає `used`.
8. Повторно використати код не можна.
9. Якщо операція не відбулась — натиснути `Код Star Club — скасувати`.

## Синхронізація карток
Повна синхронізація тепер очищає папку `Бонусні картки Star Club`: якщо карта вже відсутня в базі Star Club, вона прибирається з 1С.
