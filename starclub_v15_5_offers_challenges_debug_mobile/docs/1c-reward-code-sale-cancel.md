# Star Club — товар за зірки через 1С

## Що додано

1. Перевірка коду товару за зірки в 1С.
2. Відображення в 1С: товар, код товару 1С, кількість, ціна в грн, ціна в зірках, статус коду, клієнт і баланс.
3. Підтвердження використання коду після проведення операції.
4. Скасування активного коду в 1С.
5. Скасування активного коду в кабінеті клієнта.
6. Прострочення коду через 15 хвилин: код стає expired, зірки більше не резервуються.

## Кнопки у 1С

У формі ЧекККМ або у зручній тестовій формі можна додати 3 кнопки.

### 1. Перевірити код Star Club

```1c
Процедура ПеревіритиКодStarClubНажатие(Элемент)

	StarClubИнтеграция.ЗапитатиТаПеревіритиКодТовараЗаЗірки();

КонецПроцедуры
```

### 2. Списати код Star Club

```1c
Процедура СписатиКодStarClubНажатие(Элемент)

	StarClubИнтеграция.ЗапитатиТаПідтвердитиКодТовараЗаЗірки();

КонецПроцедуры
```

Якщо кнопка стоїть у формі чека і доступний номер чека, можна передати номер:

```1c
StarClubИнтеграция.ЗапитатиТаПідтвердитиКодТовараЗаЗірки(Объект.Номер);
```

### 3. Скасувати код Star Club

```1c
Процедура СкасуватиКодStarClubНажатие(Элемент)

	StarClubИнтеграция.ЗапитатиТаСкасуватиКодТовараЗаЗірки();

КонецПроцедуры
```

## Як показувати замовнику

1. У Star Club клієнт відкриває “За зірки”.
2. Натискає “Отримати” на тестовому товарі.
3. На екрані зʼявляється QR і ручний код.
4. У 1С натискаємо “Перевірити код Star Club”.
5. Скануємо/вводимо ручний код.
6. 1С показує: товар, кількість, ціну в грн, ціну в зірках, статус reserved.
7. Касир додає товар у чек або проводить тестову операцію.
8. У 1С натискаємо “Списати код Star Club”.
9. Баланс клієнта зменшується, код стає used.
10. Повторна перевірка цього ж коду повертає помилку, що код уже використаний.
11. Якщо код не використаний — його можна скасувати кнопкою “Скасувати код Star Club” або в кабінеті клієнта.
12. Якщо минуло 15 хвилин — код стає expired і не може бути використаний.
