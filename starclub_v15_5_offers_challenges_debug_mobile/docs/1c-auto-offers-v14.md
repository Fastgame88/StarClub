# Star Club v14 — автоматичні клубні ціни, оптові ціни та множники зірок

## Що додано

Новий endpoint:

`POST /api/1c/calculate`

Він приймає картку клієнта, магазин і чернетку товарів чека. До оплати сервер автоматично:

- знаходить активну клубну ціну для конкретного коду товару або категорії;
- знаходить відповідний оптовий рівень за кількістю;
- обирає найнижчу доступну ціну;
- знаходить найбільший активний множник зірок;
- повертає нову ціну кожного рядка, загальну знижку та очікуване нарахування.

## Правильний сценарій на касі

1. Касир додає товари в Чек ККМ за звичайною ціною.
2. Касир вибирає картку Star Club.
3. 1С викликає попередній розрахунок Star Club.
4. Ціни в рядках автоматично змінюються на клубні/оптові.
5. Касир бачить кінцеву суму до оплати.
6. Після оплати і успішного проведення 1С відправляє остаточний чек в `/api/1c/receipts`.
7. Star Club повторно перевіряє множники й нараховує правильну кількість зірок.

## Код кнопки у ФорміДокумента ЧекККМ

Додайте кнопку `Розрахувати Star Club` і прив’яжіть подію `Нажатие`:

```1c
Процедура КнопкаРозрахуватиStarClubНажатие(Элемент)

    ОтветStarClub = StarClubИнтеграция.ЗастосуватиКлубніУмовиStarClub(
        Товары,
        ДисконтнаяКарта,
        Магазин,
        Дата
    );

    Если ОтветStarClub <> Неопределено Тогда
        СуммаДокумента = Число(ОтветStarClub.final_total_cents) / 100;
    КонецЕсли;

КонецПроцедуры
```

## Автоматичний виклик після вибору картки

У наявну подію зміни поля `ДисконтнаяКарта` додайте в кінці:

```1c
Если ЗначениеЗаполнено(ДисконтнаяКарта) И Товары.Количество() > 0 Тогда
    ОтветStarClub = StarClubИнтеграция.ЗастосуватиКлубніУмовиStarClub(
        Товары,
        ДисконтнаяКарта,
        Магазин,
        Дата
    );

    Если ОтветStarClub <> Неопределено Тогда
        СуммаДокумента = Число(ОтветStarClub.final_total_cents) / 100;
    КонецЕсли;
КонецЕсли;
```

Таку саму вставку можна додати в кінець наявних подій зміни номенклатури та кількості товару. Якщо у вашій конфігурації назви подій відрізняються, залиште кнопку `Розрахувати Star Club` як гарантований ручний запуск перед оплатою.

## Як налаштовувати пропозиції

### Клубна ціна конкретного товару

- Тип: `Клубна ціна`
- Код товару 1С: точний код номенклатури, наприклад `ЦБ000008652`
- Звичайна ціна: 55 грн
- Клубна ціна: 42 грн

### Подвійні зірки для категорії

- Тип: `Множник зірок`
- Категорія з 1С: точне значення, яке 1С передає у `НоменклатурнаяГруппа`
- Множник: 2

### Оптова ціна

- Тип: `Оптова ціна`
- Код товару 1С або категорія
- Рівні, наприклад:
  - від 1 шт — 45 грн;
  - від 2 шт — 39 грн;
  - від 3 шт — 36 грн.

## Правила конфліктів

- Для ціни обирається найнижча доступна ціна між звичайною, клубною та оптовою.
- Для множників не виконується перемноження. Застосовується найбільший активний множник.
- Алкоголь, тютюн, мінімальна маржа та товари з прапорцем `no_star_accrual` не отримують зірки.
