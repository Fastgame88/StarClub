Star Club — архів правок

Скопіюй файли з архіву у свій проєкт C:\starclub з заміною.

Замінені / додані файли:
- src/index.js
- src/db.js
- src/bot.js
- public/app.js
- public/admin.js
- public/admin-desktop.html
- public/admin-desktop.css
- README_ЗАМІНА_ФАЙЛІВ.txt

Що зроблено:
1) Mini App автооновлює баланс, історію, чеки, QR-коди, прогрес і підтримку без перезапуску.
2) Після отримання QR товару за зірки кнопка «Готово» більше не залипає: модалка закривається, дані оновлюються, відкривається розділ QR-кодів.
3) В адмінці список клієнтів показує тільки ім'я і телефон, додано пошук за ім'ям/телефоном/карткою, решта відкривається через «Детально».
4) У профілі клієнта в адмінці чеки показують товари. Історія зірок і чеки показують 3 записи, кнопка «Детальніше +10» догружає ще, «Приховати» повертає до 3.
5) Додано аналітику клієнта: топ-3 товари. Біля кожного можна створити персональний QR-код на знижку.
6) Накопичувальні програми тепер видають QR на безкоштовний товар за 0,10 грн, а не просто зірки. QR діє 7 днів за замовчуванням.
7) Бот /start і /admin виправлено: перед запуском чиститься webhook, додаються команди, /admin дає вибір мобільної або комп'ютерної адмінки.
8) Додано окрему комп'ютерну адмінку: /admin-desktop.html

Після заміни виконай:

npm run check
npm start

Для Railway перевір env:
RUN_BOT=true
BOT_TOKEN=твій токен
APP_URL=https://web-production-967ed.up.railway.app
WEBAPP_URL=https://web-production-967ed.up.railway.app

Після запуску перший старт автоматично додасть нові колонки в SQLite:
- stamp_programs.reward_product_id
- stamp_programs.reward_valid_days
- personal_coupons

Важливо:
Для накопичувальних програм у адмінці бажано вказати ID товару з розділу «Товари за зірки», який треба видавати як безкоштовний QR. Якщо ID не вказати — система спробує підібрати товар за назвою/категорією, наприклад кава або багет.
