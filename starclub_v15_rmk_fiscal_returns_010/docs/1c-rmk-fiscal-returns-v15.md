# Star Club v15 — РМК, фіскальні чеки, повернення та 0,10 грн

## 1. Чому старий ЧекККМ не мав галочки "Пробитий"

Кнопка `Провести` в документі ЧекККМ лише проводить документ в обліку. Вона не завжди виконує фіскальний друк. У реальній роботі продажі йдуть через РМК / Реєстрацію продажів. Тому Star Club треба підключати саме до РМК і викликати синхронізацію лише після успішного фіскального пробиття.

Не викликайте `ОтправитьЧекВStarClub()` у `ОбработкаПроведения`. Інакше Star Club отримає чек навіть тоді, коли фіскальний реєстратор його не пробив.

Правильна точка виклику — код, де 1С вже встановила:

```1c
СтатусЧекаККМ = Перечисления.СтатусыЧековККМ.Пробитый;
Записать(РежимЗаписиДокумента.Запись);
StarClubИнтеграция.ОбробитиПробитийЧекStarClub(ЭтотОбъект);
```

## 2. Чеки без бонусної картки

Бонусна картка необов'язкова. Якщо покупець її не показав:

- 1С проводить і фіскалізує чек штатно;
- Star Club не нараховує зірки;
- API повертає успішний `skip`, а не `CLIENT_NOT_FOUND`;
- відсутність картки не блокує оплату і закриття чека.

## 3. Товар за зірки

Касир у РМК натискає кнопку `Товар за зірки`, вводить/сканує код. Модуль:

- перевіряє код;
- знаходить товар за кодом 1С;
- автоматично прив'язує картку клієнта з QR;
- додає товар у поточний чек;
- ставить технічну фіскальну ціну `0,10 грн`;
- записує QR у коментар чека;
- після успішного фіскального пробиття списує зірки один раз.

Технічна ціна задається в Railway:

```env
REWARD_TECHNICAL_PRICE_CENTS=10
```

## 4. Повернення звичайного товару

Після успішного фіскального повернення 1С викликає:

```1c
StarClubИнтеграция.ОбробитиПробитийЧекStarClub(ОбъектЧекаВозврата);
```

Сервер знаходить первинний чек та:

- при повному поверненні скасовує все первинне нарахування;
- при частковому поверненні скасовує пропорційну частину зірок;
- створює запис в історії зірок;
- не коригує нічого, якщо первинна покупка була без картки.

## 5. Кнопки в РМК

Додайте у форму РМК:

- `Товар за зірки`;
- `Розрахувати Star Club`;
- за потреби `Скасувати код`.

Готовий шаблон процедур міститься у:

`integration-1c/RMKStarClubPatch.bsl`

У шаблоні потрібно лише підставити реальну змінну поточного чека вашої форми РМК.
