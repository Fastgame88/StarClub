# StarClub ↔ 1С v27: детальна інструкція встановлення

## 1. Загальний модуль StarClubИнтеграция

У конфігураторі відкрийте:

`Конфігурація → Загальні → Загальні модулі → StarClubИнтеграция`.

Зробіть резервну копію поточного тексту модуля. Після цього повністю замініть текст модуля вмістом файла:

`integration-1c/StarClubFullIntegration_COMPLETE_v27.txt`.

Це повний модуль на базі `COMPLETE_v26_RMK`; попередні процедури синхронізації клієнтів, магазинів, товарів, цін, QR, чеків і повернень не видалені. У кінець модуля додані функції v27:

- `StarClubЗіркиЗКопійок()`;
- `StarClubКопійкиЗЗірок()`;
- `StarClubПідготуватиПоповнення()`;
- `StarClubПідготуватиЗРешти()`;
- `StarClubЗавершитиПоповнення()`;
- `StarClubСкасуватиПоповнення()`;
- `StarClubЗаблокуватиКредитНаФормі()`;
- `StarClubЗаписатиСумиУФормуРозрахунку()`.

## 2. Напис «з решти»

У формі розрахунку знайдіть елемент або напис, де зараз вказано `із здачі`, `зі здачі` або `сдача`. Змініть лише заголовок елемента на:

`з решти`.

Назву внутрішнього реквізиту змінювати не потрібно, щоб не ламати існуючі виклики.

## 3. Кнопка «Поповнити зірки» в РМК

Відкрийте форму документа/обробки РМК, де вже розташовані кнопки **Star код** і **Пошук**. Додайте поруч команду:

`ПоповнитиЗіркиStarClub`.

Заголовок кнопки:

`Поповнити зірки`.

Обробник команди має:

1. Перевірити, що вибрана картка StarClub.
2. Запитати суму поповнення у гривнях.
3. Запитати спосіб оплати: `Готівка` або `Картка`.
4. Викликати `StarClubИнтеграция.StarClubПідготуватиПоповнення(...)`.
5. Зберегти отриманий `operation_id` у реквізиті форми, наприклад `StarClubОпераціяПоповнення`.
6. Додати суму до колонки `СуммаStarClub` і до загальної суми форми розрахунку.
7. Після успішного проведення/фіскалізації чека викликати `StarClubЗавершитиПоповнення(...)`.
8. При скасуванні оплати викликати `StarClubСкасуватиПоповнення(...)`.

Приклад обробника:

```bsl
Процедура ПоповнитиЗіркиStarClubНажатие(Элемент)
    Если Не ЗначениеЗаполнено(ДисконтнаяКарта) Тогда
        Предупреждение("Спочатку виберіть картку Star Club");
        Возврат;
    КонецЕсли;

    СуммаПополнения = 0;
    Если Не ВвестиЗначение(СуммаПополнения, "Сума поповнення, грн") Тогда
        Возврат;
    КонецЕсли;
    Если СуммаПополнения <= 0 Тогда
        Предупреждение("Сума має бути більшою за нуль");
        Возврат;
    КонецЕсли;

    ВидОплаты = "Готівка"; // у вашій формі можна замінити на вибір зі списку
    Ответ = StarClubИнтеграция.StarClubПідготуватиПоповнення(
        ДисконтнаяКарта.Код,
        СуммаПополнения,
        ВидОплаты,
        Магазин,
        КассаККМ,
        Пользователи.ТекущийПользователь()
    );

    StarClubОпераціяПоповнення = Ответ.operation_id;
    СуммаStarClub = СуммаПополнения;
    StarClubИнтеграция.StarClubЗаписатиСумиУФормуРозрахунку(ЭтаФорма, СуммаStarClub, СуммаДокумента);
КонецПроцедуры
```

Назви `ДисконтнаяКарта`, `Магазин`, `КассаККМ`, `СуммаДокумента` замініть тільки тоді, коли у вашій формі вони мають інші фактичні назви.

## 4. Додавання суми StarClub у «Сформировать»

Відкрийте модуль форми розрахунку, де формується таблиця платежів/звіт `Сформировать`.

Перед заповненням першої колонки загальної суми додайте:

```bsl
ОбщаяСумма = ОбщаяСумма + СуммаStarClub;
```

Або викличте:

```bsl
StarClubИнтеграция.StarClubЗаписатиСумиУФормуРозрахунку(
    ЭтаФорма,
    СуммаStarClub,
    СуммаЧекаБезStarClub
);
```

У табличній частині повинні зберігатися окремо:

- сума готівкою;
- сума карткою;
- `СуммаStarClub`;
- загальна сума, що дорівнює сумі всіх трьох джерел.

Для поповнення і для «з решти» backend використовує один журнал `change_accrual_operations`, тому операція не загубиться між натисканням оплати і проведенням чека.

## 5. Блокування кнопки «Кредит»

У процедурі зміни дисконтної картки, яка реально викликається у вашій формі (`ДисконтнаяКартаПриИзменении()` або аналог без `Экспорт`), після успішного визначення клієнта StarClub додайте:

```bsl
StarClubИнтеграция.StarClubЗаблокуватиКредитНаФормі(ЭтаФорма, Истина);
```

Коли картку очищено або вибрано не StarClub-картку:

```bsl
StarClubИнтеграция.StarClubЗаблокуватиКредитНаФормі(ЭтаФорма, Ложь);
```

Функція перевіряє поширені назви кнопки: `Кредит`, `КнопкаКредит`, `ОплатаКредит`, `КредитнаяОплата`. Якщо у вашій конфігурації назва інша, додайте її в масив усередині `StarClubЗаблокуватиКредитНаФормі`.

## 6. Завершення операції тільки після проведення чека

У процедурі, яка спрацьовує після успішного проведення/друку чека, після отримання номера чека додайте:

```bsl
Если ЗначениеЗаполнено(StarClubОпераціяПоповнення) Тогда
    StarClubИнтеграция.StarClubЗавершитиПоповнення(
        StarClubОпераціяПоповнення,
        ДокументЧек.Номер,
        ФискальныйНомер,
        Магазин,
        КассаККМ,
        Пользователи.ТекущийПользователь()
    );
    StarClubОпераціяПоповнення = "";
КонецЕсли;
```

Не викликайте `complete` до фактичного проведення чека. До цього моменту операція має статус `pending`; при помилці оплати її можна безпечно скасувати.

## 7. Нарахування «з решти»

У формі розрахунку після введення суми готівки розрахуйте залишок:

```bsl
СуммаРешти = Макс(0, ВнесеноГотівкою - СуммаКОплате);
```

Коли касир підтверджує зарахування решти на StarClub:

```bsl
Ответ = StarClubИнтеграция.StarClubПідготуватиЗРешти(
    ДисконтнаяКарта.Код,
    СуммаРешти,
    Магазин,
    КассаККМ,
    Пользователи.ТекущийПользователь()
);
StarClubОпераціяПоповнення = Ответ.operation_id;
СуммаStarClub = СуммаРешти;
```

Backend нарахує рівно стільки зірок, скільки копійок у сумі: 1,00 грн = 100 зірок.

## 8. Заборонені групи товарів

Backend приймає з 1С у кожній позиції:

- `group_external_id`;
- `group_name`;
- `group_path` або `group_path_json`.

Повний модуль v27 уже використовує функції `StarClubДодатиКодиТоваруІГрупи` і `StarClubШляхКодівГруп`. Під час відправки товарів і чеків не прибирайте ці поля. Алкоголь і тютюн надалі блокуються прапорцями, а додаткові групи блокуються за кодом групи ЄКА/1С, який адміністратор вибере в адмінці.

## 9. Перевірка API

Потрібні маршрути backend:

- `POST /api/1c/change-accrual/prepare`;
- `POST /api/1c/change-accrual/complete`;
- `POST /api/1c/change-accrual/cancel`;
- `POST /api/1c/receipts`;
- `POST /api/1c/calculate`.

У всіх запитах зберігається заголовок:

`x-starclub-token: значення ONEC_API_KEY`.

## 10. Оновлення конфігурації

Після заміни модуля:

1. Виконайте `Конфігурація → Перевірка конфігурації`.
2. Оновіть конфігурацію бази даних.
3. Перезапустіть 1С.
4. Виконайте тестовий пошук клієнта.
5. Проведіть тестове поповнення 1,00 грн: очікується +100 зірок.
6. Проведіть тестове зарахування решти 0,50 грн: очікується +50 зірок.
7. Перевірте, що при вибраній StarClub-картці кнопка «Кредит» недоступна.
8. Перевірте таблицю `Сформировать`: `СуммаStarClub` входить у загальну суму першої колонки.
