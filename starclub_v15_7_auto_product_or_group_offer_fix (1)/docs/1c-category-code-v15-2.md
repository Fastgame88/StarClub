# Star Club v15.2 — групи товарів 1С

У цій конфігурації група на скріні є папкою довідника **Номенклатура**. Тому її код знаходиться в `Номенклатура.Родитель.Код`, а не обов’язково в `Номенклатура.НоменклатурнаяГруппа.Код`.

Модуль тепер спочатку читає `НоменклатурнаяГруппа`, а якщо вона порожня — бере `Родитель`.

Для діагностики в JSON передається `category_source`: `НоменклатурнаяГруппа` або `Родитель`.

Після заміни модуля знайдіть у ньому рядок `v15.2-parent-group-fallback`, натисніть Ctrl+S, F7 і перезапустіть 1С:Підприємство.
