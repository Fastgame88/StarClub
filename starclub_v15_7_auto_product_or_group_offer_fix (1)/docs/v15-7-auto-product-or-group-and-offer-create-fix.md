# Star Club v15.7

## Автоматичне визначення: товар чи група

У формах накопичувальних програм, челенджів і пропозицій можна вводити один код із 1С.
Система перевіряє його одночасно як:

- код конкретного товару;
- код або назву безпосередньої групи;
- код або назву будь-якої батьківської групи у повному шляху.

Тому код конкретного товару діє тільки для цього товару, а код групи — для всіх товарів у ній і у вкладених підгрупах.

## Виправлення створення пропозицій

Форма пропозиції тепер має одне обов'язкове поле «Код товару або групи з 1С».
Для множника зірок додана перевірка, що множник більший за 1.
Помилка API тепер показується користувачу, кнопка не зависає без пояснення.

Сервер зберігає введене значення як ціль пропозиції і перевіряє його через універсальне зіставлення товару/групи.
