# Star Club v15.8 — виправлення створення пропозицій

Причина помилки `offers is not a function` була у фронтенді адмін-панелі: масив відповіді API мав ім'я `offers` і перекривав функцію `offers()`. Після успішного POST код намагався викликати масив як функцію.

Виправлено перейменуванням локальних масивів:
- `offers` → `offerItems`
- `challenges` → `challengeItems`
- `news` → `newsItems`
- `clients` → `clientItems`
- `qrs` → `qrItems`

Це також запобігає аналогічним помилкам у редагуванні/видаленні новин і челенджів.
