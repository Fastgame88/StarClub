# Star Club Admin v12 — mobile-first

Оновлена адмін-панель спеціально для роботи через Telegram Mini App на телефоні.

## Що змінено

- окремий мобільний верхній бар;
- нижня навігація для основних розділів;
- bottom-sheet меню «Ще»;
- таблиці на телефоні автоматично перетворюються на картки;
- форми перебудовуються в одну колонку;
- збільшені кнопки та області натискання;
- враховано safe-area iPhone;
- Owner бачить розділ адміністраторів у мобільному меню;
- резервний ADMIN_API_KEY перенесено в додаткове меню;
- desktop-версія збережена.
